# Periodic Tasks (Heartbeat)

This file defines your autonomic nervous system. Check these tasks every 30 minutes.

## Morning Routine (08:00)
-   [ ] Check the date and time.
-   [ ] Search for "top tech news" and "world news headlines".
-   [ ] Send a brief morning briefing to the user via Telegram.

## Evening Reflection (22:00)
-   [ ] Read the day's chat logs from `sessions/`.
-   [ ] Summarize key events, decisions, and mood into a new entry in `memory/daily_logs.md`.
-   [ ] If there are important facts about the user, update `USER.md`.

## Maintenance (Every 4 hours)
-   [ ] Check if `memory/` files are getting too large. If so, summarize older entries.
