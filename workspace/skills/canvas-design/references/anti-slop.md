# The tells of a generic page

These are what a model produces when it has no point of view. Notice them in your own draft and replace them.

| The tell | Why it reads as generic | Do this instead |
| --- | --- | --- |
| A purple-to-blue gradient hero on a dark ground | The default of every generated page | Take the colour from the subject: the roast, the river, the paper, the product |
| Everything centred | Centring is the absence of a layout decision | Left-align text, use an asymmetric hero, align to a strong edge |
| Three identical feature cards with emoji icons | Equal weight means no priority | One featured item, then a list; draw real icons or use none |
| Rounded card around every block, with a shadow on every card | Depth everywhere is depth nowhere | One level of elevation, used for what is actually interactive or floating |
| Inter or system sans for everything, all one weight | No hierarchy of voice | A distinctive display face for headings, a quiet face for body, two weights |
| "Welcome to X", "Your all-in-one solution" | Says nothing a visitor can use | State what it is and what happens when you tap |
| Lorem ipsum, "Feature 1", "John Doe", round fake statistics | Reveals nothing was designed | Real names, places, numbers, or an honest draft note |
| A hover-only effect | Invisible on a phone | Make it work by touch first |
| Animation on everything, 400–800ms | Slow, tiring, repeated | Animate the few moments that matter, 150–250ms |
| A contact form that does nothing | A dead end that looks alive | Make it work in the page, or replace it with the real way to reach them |
| Dark mode as the only mode, with grey text on black | Low contrast, same as every demo | Pick the ground that fits the subject; check contrast |
| All sections the same height and rhythm | Monotone scroll | Vary scale: a loud section, a quiet one, a dense one |

## Taste, practically

- Look at the thing you would be proud to show someone who builds interfaces for a living. What would they point at? Make sure that detail exists.
- Details that nobody notices are the point: consistent radii, one spacing scale, aligned baselines, a focus ring, an empty state that helps, a press that responds.
- Cohesion beats cleverness. The easing, the radius, the type and the copy should feel like one person made them.
- When something feels off and you cannot say why, remove an element before you add one.
