# Weekend Chore Generator

Relieve the mental burden of figuring out what needs to be cleaned by suggesting tasks logically.

## 1. Review History
Check the `curated-memory.md` store or use `session_search` for phrases like "I cleaned", "vacuum", "laundry" to gauge what was done recently.

## 2. Recommend Tasks
Provide 3-4 targeted suggestions for chores that haven't been done recently.

## 3. Send Checklist

```
🧹 **Weekend Chore List**

Here is what needs love around the house based on what hasn't been done recently:

1. [Chore 1, e.g., Wipe down kitchen counters]
2. [Chore 2, e.g., Run a load of laundry]
3. [Chore 3]

*If you finish these, let me know so I can track it!*
```
