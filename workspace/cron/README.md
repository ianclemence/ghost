# Ghost Cron Jobs

This directory stores scheduled tasks and jobs managed by the agent's internal cron service.

- **`jobs.json`**: Contains the active cron jobs, their schedules, and payloads.

## Note
These files are automatically updated by the agent when you add or modify scheduled tasks (e.g., "Remind me every day at 8am"). They are excluded from git tracking to keep your schedule local and private.
