# Project Ghost: Personal AI Presence (Pi Edition)

## A Sovereign, Persistent Digital Companion

Ghost is a dedicated personal AI presence that lives on your Raspberry Pi, remembers everything, and grows with you. Unlike standard chatbots, Ghost is designed for **continuity** and **presence**, utilizing the efficiency of **PicoClaw** and the intelligence of **Kimi K2.5**.

**Key Differentiation**: Ghost is not just a bot. It is a presence that witnesses your life through Telegram, maintaining a continuous thread of memory and context.

---

## The Problem (Solved)

| Dimension      | Standard AI                     | Ghost (Pi Edition)                                                 |
| -------------- | ------------------------------- | ------------------------------------------------------------------ |
| **Privacy**    | Data locked in proprietary apps | **Hybrid Sovereignty**: Local memory files, API for reasoning only |
| **Continuity** | Session-based (resets often)    | **Lifetime**: Persistent workspace & memory files on your SD card  |
| **Access**     | App-bound, high latency         | **Instant**: Always-on Telegram bot running on your local Pi       |

---

## The Solution: Ghost Pi

A "Headless" Ghost implementation that fits on standard commodity hardware.

1.  **Hardware**: Raspberry Pi 5 (8GB RAM) + 32GB SD Card.
2.  **Core Engine**: **PicoClaw** (Go-based Agent) - Ultra-lightweight (<10MB RAM), fast boot.
3.  **Cognition**: **Kimi K2.5 API** - Handling complex reasoning, vision, and 256K context.
4.  **Interface**: **Telegram** - Secure, cross-platform, voice/text/image support.

## Memory System

Adapted for 32GB SD Card (Text/File-based efficiency):

| Layer          | Implementation        | Content                              |
| -------------- | --------------------- | ------------------------------------ |
| **Session**    | `sessions/` (JSON)    | Active conversation history          |
| **Episodic**   | `memory/` (Markdown)  | Daily logs, key events, user inputs  |
| **Reflective** | `HEARTBEAT.md`        | Periodic summaries generated by Kimi |
| **Identity**   | `USER.md` / `SOUL.md` | User preferences and Agent persona   |

**Reflection Engine**: PicoClaw's `HEARTBEAT` triggers a Kimi task every night to read the day's logs and append insights to `memory/summary.md`.

## User Experience

### Setup (The Awakening)

1.  **Flash SD Card**: Install Raspberry Pi OS Lite.
2.  **Deploy PicoClaw**: Single binary download.
3.  **Configure**: Add `config.json` with Kimi API Key & Telegram Bot Token.
4.  **Awaken**: Run `./picoclaw gateway`.
5.  **Connect**: Send `/start` to your Telegram Bot.

### Interaction Modes

- **Chat**: Natural conversation. Kimi K2.5's "Thinking" mode handles complex questions.
- **Vision**: Send a photo to Telegram; Ghost analyzes it using Kimi Vision.
- **Voice**: Send a voice note; Ghost listens (transcribes via Groq/API) and replies.
- **Proactive**: Ghost sends you a message at 8 AM with news or agenda (via PicoClaw Cron).
