Enter the admin password to manage your Ghost.

Set a new password over SSH, or from the recovery panel if Ghost won't start:

Over SSH (Ghost running)
sudo ghost reset-password --force
Recovery panel (Ghost won't start)

Reboot the device, then open http://ghost.local:8766 within 15 minutes and choose "Reset admin password".
